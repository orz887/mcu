当前样板、接线与硬件勘误

更新：2026-09-23。先读本文，再使用归档中的 PCB、BOM 或外壳资料。

归档中的 2026-09-18 PCB 制造文件含已确认的 SW1～SW5 按键接法错误，不能照原样直接复产。 文件保留的是实际样板对应的设计，便于学习和排查；文件名中的 REVIEWED、旧文档中的“DRC 为 0”或“可打样”不代表按键电路正确。本次软件正式发布没有替你修改原理图、PCB、Gerber 或 SMT 文件。

本文的“已确认”包括用户提供的现象，并不表示我们直接测过样板。

2. 先认清方向和编号

把 有元件的一面朝向自己，USB 接口放在上方，五个按键的位置放在下方。右侧竖直的 8 孔连接器是 J2。J2 最下方是 1 脚，最上方是 8 脚。

           USB 在上方
             J2
        8  GND（备用）
        7  RST
        6  DC
        5  CS
        4  CLK
        3  DIN
        2  GND
        1  3V3  ← 方形金属焊盘
             J3（下载）
             J4（串口）
             J5（电位器）
             J6、J7（扩展）
         按键位置在下方

“方形焊盘”指 PCB 上的金属焊盘，所有排母插孔看上去都是方形，不可用塑料孔的形状判断 1 脚。J3～J7 的四个脚在这个观察方向下从左到右为 1、2、3、4；从板底观察会左右镜像。

3. 电源、下载器与串口各做什么

J1 Type-C 输入 USB 5V，U2 AP2114H-3.3TRG1 把它变为板上 3.3V。这块板的 Type-C 仅供电，不提供 USB 下载或 USB 串口功能。 下载用 J3，串口通信使用 J4。

接线、改线、拔插屏幕前先关闭主板、下载器和 USB 转串口的供电。电压用通电后的直流电压档测；电阻和通断必须在全部断电后测。避免表笔同时碰到相邻脚。

主板由 USB 供电时，小型 ST-LINK V2 的 3.3V/5V 输出和 USB 转串口的 VCC 均留空，避免两路电源相互连接。模块标有“3.3V”的电源脚不等于它的 TXD 一定是 3.3V 逻辑，应核实转换器的逻辑电平设置。

J3：小型 ST-LINK V2 下载

J3 脚号 主板信号 接法
1 +3V3 当前小型 ST-LINK V2 接法留空，主板自行 USB 供电
2 SWDIO / PA13 下载器 SWDIO
3 SWCLK / PA14 下载器 SWCLK
4 GND 下载器 GND

SWDIO 传输调试数据，SWCLK 提供时钟，GND 建立共同的电压参考。当前 J3 没有 NRST 引脚；已验证的软件设置为 SWD、100kHz、Normal、Software reset。正常更新程序不需要改 RDP 读保护或其他选项字节。

若以后换成具有独立 VTref 电压检测输入的正规调试器，应按该调试器说明接检测端，不能照搬“小型下载器的 3.3V 电源输出留空”来判断所有设备。

J4：USB 转串口

J4 脚号 主板信号 USB 转串口一端
1 +3V3 不接电源脚
2 UART_TX / PA9 RXD
3 UART_RX / PA10 TXD
4 GND GND

主板的“说话端”TX 要接电脑转换器的“听话端”RX，所以 TX/RX 交叉。终端设 115200 波特率、8 数据位、无校验、1 停止位、无流控，命令末尾带换行。先发 status 或 help；小型 ST-LINK V2 本身不能替代这个串口模块。

4. J2：微雪 2.42 英寸 SSD1309 屏幕

本壳体适配微雪 2.42inch OLED Module 白屏 SKU25742，模块外形 61.5×39.5mm，保持出厂 SPI 接口设置。早期讨论的 72×43mm 其他模块不属于本版适配对象。

J2 脚号 屏幕标识 对应信号
1，最下方 VCC +3V3
2 GND 地
3 DIN PA7，送入屏幕的数据
4 CLK PA5，时钟
5 CS PA4，片选
6 DC PB8，区分命令与像素数据
7 RST PB9，复位屏幕
8，最上方 不接 备用 GND

只用前七脚即可，八脚排母不代表屏幕需要八根线。按两端信号名对应，不按排线颜色猜测。当前 1 脚为 3V3、2 脚为 GND，早期 V3 接线表的电源顺序不能再使用。

GPIO 模拟 SPI 和硬件 SPI 都是在传输 SPI 信号；区别是由软件逐位改变引脚，还是交给 MCU 的专用外设自动发送。当前正式游戏沿用用户验证过的 GPIO Mode 0、高位先发方式，接线不变。写屏成功计数只说明程序完成发送，不具备“屏幕已收到并显示”的反馈能力。

5. 声音、旋钮、指示灯和蜂鸣器

麦克风 MK1

板上 CMA-6542PF 驻极体麦克风通过偏置、耦合和 LMV358 模拟放大电路，将声音变化送到 MCU 的 PA0（ADC_AUDIO）。ADC 把电压转换成数字，程序从一组数字计算声音强度，再决定是否让小鸟上跳。

已焊好的麦克风不需要再接外部信号线。不要向 PA0 或麦克风信号点接 5V。上电约 1.5 秒保持安静，给程序一个测量环境底噪的机会；短吹触发，持续大声不会无限连续上跳。

电位器接 J5

J5 脚号 用途
1 +3V3，接电位器一个外侧端
2 PA1 / ADC_POT，接滑臂端
3 或 4 GND，接电位器另一个外侧端

10kΩ 线性电位器可用于这个练习。三脚电位器通常中间脚是滑臂，但应以实物资料或电阻测量确认；只交换两个外侧端会反转旋转方向。默认不让旋钮改变声控门限，发 pot on 后启用；pot off 关闭。电位器提供的是 0～3.3V 范围内的模拟输入，不是用来给主板调供电电压。

D1、D2 和 BZ1

位号 作用 电路与软件关系
D1 电源指示灯 由 3.3V 经限流电阻供电，亮了不等于程序已启动
D2 程序状态灯 PC13 控制，低电平亮；正常游戏心跳短闪用于确认主循环仍在运行
BZ1 无源压电蜂鸣器 PA8 经 R13 470Ω 到蜂鸣器，另一端接地；约 4kHz PWM 产生短音

蜂鸣器不是扬声器或麦克风，不需要再接杜邦线。当前程序用定时器产生方波，设置到期时间后自动停音，不靠长时间等待。游戏音效开启后，程序短暂抑制声音触发，减少蜂鸣器被当成吹气；仍应实测同一外壳内的声学反馈。可发 mute on 关闭音效，mute off 开启；调音模式保持静音。

6. 必须理解的按键接法错误

四脚轻触开关不是四个互相独立的端子。本板使用 TS-1187A-B-A-B（C318884），其 1～2 脚内部常通、3～4 脚内部常通；按下才把这两组连在一起。

在元件面、USB 在上的方向，当前封装如下：

        左上 1 ═════ 2 右上    上排内部始终相连
                ↓ 按下才接通 ↓
        左下 3 ═════ 4 右下    下排内部始终相连

当前制造文件却把 1/3 接信号、2/4 接 GND，这就使信号经开关内部永久接地。SW5 的信号是 NRST，所以 MCU 一直处于复位；SW1～SW4 的信号是游戏按键输入，所以一直表现为按住。

按键 信号 MCU 正确用途
SW1 KEY1 PB15 上跳 / 回到游戏
SW2 KEY2 PB14 暂停 / 继续
SW3 KEY3 PB13 游戏、自检、调音之间切换
SW4 KEY4 PB12 重新标定声音门限
SW5 NRST MCU 第 7 脚 硬件复位

当前固件将 SW1～SW4 设置为上拉输入，只有确认按键稳定释放后才接受按下事件；持续低电平的键会被屏蔽，BLOCKED=F 表示四键都没有正常释放。这只是让其他功能继续运行，不是修好了按键。 不得把 GPIO 改成输出高电平去“顶住”短接。

已有样板如何继续教学

当前最简单的学习路线是保留已恢复运行的主板，先学声控、屏幕和串口；把按键返修作为独立硬件练习，由有贴片返修经验的人操作。拆焊前断开全部供电，不能硬撬焊盘。

需要临时练习 GPIO 输入时，可由老师拆下对应的错误开关，确认信号已不再被短接，再用两根线外接一个经万用表确认“松开断路、按下导通”的两脚常开按钮：一根接该开关原 1 脚信号焊盘，另一根接原 2 脚 GND 焊盘。必须先移除原开关；原开关留在板上时，外接按钮不能解除短路。外接按钮和线束不属于原 V4 外壳的机械适配范围。

SW5 拆除后可通过 USB 断电重启；若要外接复位按钮，使用同样的常开结构连接 NRST 与 GND。不要短接 NRST 到 3.3V，也不要为正常下载反复修改 RDP。这里没有提供已完成切线、飞线或已返修的样板证明。

下一版 PCB 应怎样改

一种正确分组是 1/2 全接信号，3/4 全接 GND，上下两组互换也可以。应修正原理图器件映射和 PCB，检查全部五个开关，再重新导出同一版本的工程、Gerber、BOM 和贴片坐标。

不要将原开关简单旋转 90° 后强行装回：该封装横纵焊盘间距不同。返修和新版生产前，都应拿未安装的开关实测常通组，与封装编号逐一对应。DRC 检查线间距和网络连接，不会自动知道器件内部哪两个触点永久连接；这是本项目适合学习的一次真实问题。

7. V4 外壳资料怎么用

外壳约 95×90×32.4mm，主板约 70×70×1.6mm。主板通过四角支承和板外压片固定，屏幕装在独立托架上，再固定到可拆主盖。

  • print/ 中 9 个 STL：底壳、主盖、按键面板、屏托架、4 个主板压片、1 个公差试片。实际装入外壳的是前 8 件，试片不装入。
  • step/ 是 9 个 EDA 原生分件 STEP；assembly/ 中的 STEP/GLB 是完整装配展示，不能当一个零件整体打印。
  • assembly/ASSEMBLY_GUIDE.md 带完整装配、爆炸、主板固定和上盖翻面图，按其顺序和螺丝表装配。
  • 螺丝共 14 颗：M3×8 六颗、M3×6 两颗、M2×6 两颗、M2.5×5 四颗；屏托架相关的 6 颗螺丝使用图解中要求的垫片。

先裸板运行，再断电试装。用公差试片检查孔径和螺丝配合，清理毛刺，检查插件脚、插头高度、线束弯曲和拆盖余量。不要靠玻璃、屏幕排线或背面元件承力，不用电批硬拧塑料柱。设计几何检查不代替实际打印公差和装配验证。

V4 工程名称含“最新主板”，指 相对于 2026-09-18 的主板布局同步，不代表后来的按键错误已修正。外壳副本只用于外壳，PCB/SMT 的主板来源始终是 Board1 → PCB1；当前该主板仍需先完成上述按键修订。

9. CAD 脚本再生成注意事项

只查看或打印现有 STEP/STL 不需要运行 Python。进阶学习再运行生成脚本，先使用工程副本。

flappy-bird-enclosure-sync-20260918/build_assembly_views.py 通过相对目录读取自身 validation.json、step/，并读取相邻 flappy-bird-enclosure-v3/easyeda/layout.json、reference/Waveshare_25742_official.step 与相邻 flappy-bird-pcb-repair-20260918/pcb_final.json。复制源码时需保留这三个相邻目录名和相关文件。运行需要 CadQuery、NumPy、Pillow、trimesh、VTK 以及中文字体；脚本原字体路径为 /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc，其他系统需调整。

V3 的 cad/build_easyeda_native.py 依赖本目录 evidence/native_clean_baseline.json，生成 EDA 外壳记录和排布表。V3 的 cad/verify_enclosure.py 依赖 easyeda/layout.json、easyeda/export_step/、evidence/final_primary_components.json、reference/Waveshare_25742_official.step，用于历史几何验证和导出。

V4 的 prepare_sync.py、verify_sync.py 含开发机绝对路径，复用时要先调整；它们所需的历史快照和几何源不能只复制一个脚本就丢掉。cad/eda_bridge.py 还含历史工程 UUID 和本地 127.0.0.1:49620 API 地址，涉及 EDA 文档创建、写入和导出，不属于新手烧录流程。先读脚本并改为自己的测试工程，再考虑执行；不要把历史请求直接发送到正在工作的主板工程。
