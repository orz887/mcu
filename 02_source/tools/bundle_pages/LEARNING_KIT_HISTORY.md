# 历史、原始工作区与证据

这些文件用于复盘设计过程，不是新人第一次烧录或下单的入口。**现行固件在01_firmware，现行教学判断以课程和硬件勘误为准。**

- `past_deliveries/`保留本机现有的历史固件、屏幕诊断、PCB和各版外壳交付ZIP。
- `original_workspace/`保留全部已有`flappy-bird-*`项目资料目录，包括PCB布线快照、DRC/DFM分析、按键/复位排查、V1～V4模型、CAD生成脚本及早期交接。
- PCB、V4和V3目录仍为相邻目录，便于追踪CAD脚本的相对读取依赖。

旧文档中可能有后来被推翻的内容，例如早期屏幕尺寸、J2电源针序、硬件“可打样”结论、默认静音、绝对路径以及尚未发现的按键错误。阅读时先看日期，再与现行勘误核对。

历史`.json`请求和`.py/.ps1`脚本可能包含对EDA工程的写操作；把它们当作可读证据，**不要为了“完成安装”而批量运行**。移机再生成CAD还需相应Python库和字体，旧绝对路径也需调整。

这些归档保持原件内容，没有静默修正旧报告的结论；包内当前入口承担版本说明和纠错作用。
