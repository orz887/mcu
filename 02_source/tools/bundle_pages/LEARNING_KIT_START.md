# 从声控小鸟开始学嵌入式

**教学正式版 v1.0.0 · 2026-09-23**

这是一套可以接线、烧录、修改和拆开研究的STM32项目。你对麦克风短吹，小鸟上跳；OLED显示游戏，蜂鸣器在得分或碰撞时短响。沿着这个小作品，可以把电路、C语言、定时器、中断、采样、通信和外壳装配连成一条学习路线。

**先把整个tar.gz解压，再双击本目录的`index.html`。** 网页教程和包内图片离线可读；首次安装工具、下载编译依赖及访问官方网页仍需要联网。

> **制作新板前必读：现有PCB制造档含已知按键接法错误，按实物原样归档，并未完成硬件改版。不要把文件名中的REVIEWED或旧文档中的“可打样”当作可直接复产的结论。** 详见[硬件实物与勘误](02_source/docs/HARDWARE_AS_BUILT_AND_ERRATA.md)。

## 第一次打开，按这个顺序

1. **认识作品：**阅读[零基础完整课程](02_source/docs/COURSE_ZERO_TO_EMBEDDED.md)的导读和基础章节，先知道每个模块做什么。
2. **确认已有样板状态：**阅读[硬件勘误与接线](02_source/docs/HARDWARE_AS_BUILT_AND_ERRATA.md)，由老师确认电源、下载器、屏幕和按键问题。
3. **先运行一次：**按[游戏版上手步骤](02_source/docs/GAME_QUICKSTART.md)烧入[正常游戏HEX](01_firmware/flappy_f103.hex)。上电安静约1.5秒，显示`BLOW TO START`后短吹。
4. **读最短的入口：**打开[main.c](02_source/src/main.c)，对照[代码设计指南](02_source/docs/BEGINNER_GUIDE.md)理解七个循环任务。
5. **完成小实验：**课程内有10项实验，每次只改一个参数，记录原值、现象和解释，再继续下一项。
6. **理解制造与装配：**最后看[PCB材料](03_hardware/README.md)、[外壳与装配](04_enclosure/README.md)及历史排错记录。

## 正式版与目前的验证范围

- 用户已确认GPIO SPI正常游戏版测试正常，正式版沿用相同的24次GPIO等待。
- v1.0.0默认开启得分/碰撞约4kHz、60ms短音；鸣叫开始后屏蔽声控触发300ms，并要求重新安静再触发。`mute on`关闭游戏音效，`mute off`恢复。
- 新蜂鸣器行为通过电脑端回归测试，实际响声和与麦克风的声学影响还需这次烧录确认。
- 兼容版保留更慢的192次等待，作为显示问题的备选；通常先用正常游戏版。
- 原按键硬件错误与外壳未完成整套实物装配验证的事实均保留在勘误中。正式版是软件教学发布，不代表全部硬件已量产验收。
- 题目要求中的ADC误差、调音精度、长时间稳定性，应按课程实验真实记录，不能从“游戏能玩”推定全部合格。

## 对老师的建议

第一周先让学生成功烧录并解释供电、地线和下载线；第二周读懂GPIO和主循环；随后再讲中断、DMA与状态机。不要把所有寄存器、PCB规则、调音数学一次讲完。每次实验让学生先预测、再观察，最后用自己的话解释差异。

保留一份未修改源码作对照；让学生在另外的工作目录里修改。按键返修、焊接和新板下单由有经验的人复核。课程末尾附有学习路线、检查题和可继续探索的方向；本项目是一条入门路线，不是对整个嵌入式行业知识的替代。

## 校验与再构建

包外`.tar.gz.sha256`用于核对压缩包；包内`BUNDLE_MANIFEST.json`和`SHA256SUMS`记录逐文件哈希。`VALIDATION.json`记录链接及发布检查结果。校验原件后，修改源码是正常学习行为，此时文件哈希自然会变化。

Windows PowerShell核对压缩包：

```powershell
Get-FileHash .\Flappy_Bird_Learning_Kit_v1.0.0_20260923.tar.gz -Algorithm SHA256
```

完整源码在`02_source`。构建固件的详细步骤见课程和源码README；本包不附带Windows安装器或特定系统的工具链缓存，PlatformIO首次构建会按固定版本自动下载依赖。
